# iTantra phrase codebook — English
#
# One phrase per line. The LINE ORDER IS A WIRE CONTRACT: a phrase's position in this
# file is the number that travels on the link. Both devices must hold an identical file
# or a phrase id decodes to the wrong sentence.
#
#   APPEND ONLY. Never reorder, never delete, never edit an existing line's meaning.
#   Retiring a phrase means leaving it in place and stopping using it.
#
# Blank lines and lines starting with # are ignored and do not consume an id.
#
# Chosen for what disaster traffic actually repeats — water, boats, roads, medicine,
# people, and the handful of acknowledgements that keep a net orderly. Coverage, not
# elegance, is the point: a phrase that is never sent saves nothing.
